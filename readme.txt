== Description ==

Our <a href="https://github.com/bijit027/pollquest" rel="friend" title="PollQuest">PollQuest</a> WordPress plugin helps you increase website engagement and improve your site by collecting real feedback from your visitors in realtime.

Most analytics tools show you WHAT your users are doing, but now with PollQuest you can finally see WHY they are doing it. Collecting real user feedback allows you to learn what features are missing, find out why visitors leave, understand what your audience wants, and make smarter decisions — faster. The sky's the limit with what you can ask.

Our goal with PollQuest is to help website owners grow their business by understanding what users are really thinking, so that you can maximize each visitor's experience.

Launching a survey is extremely simple, with no coding needed. Simply install PollQuest, choose from our built-in templates or create your own from scratch, and start collecting feedback immediately.

The PollQuest survey widget appears on your website automatically, allowing you to gather insights right when and where you need them.

You can create an unlimited number of surveys, target them to specific pages or audiences, and filter results by date range — all from inside your WordPress dashboard.

Want to run an NPS&reg; survey? No problem! With our built-in templates and per-question charts you can launch a survey like this in seconds.

Want to run a custom poll for your website visitors? With real-time analytics and CSV export, you can easily collect and act on any type of feedback.

* Easy Setup - Launch a survey in seconds with no coding or development needed

= Note for Beginners =

Like many WordPress plugins, PollQuest is only available for self-hosted WordPress sites (WordPress.org). This means you will need to switch from WordPress.com to WordPress.org if you want to use this plugin on your website.

== Frequently Asked Questions ==

= How does PollQuest help me? =

Most analytics tools show you what is happening on your website, but with PollQuest you can finally learn why visitors are engaging with your content, store, or community by asking simple questions. Use PollQuest to ask why someone took an action, or why they didn't, so that you can optimize each visitor's experience.

= Where can I find support? =

Support is available on the WordPress.org plugin support forums.

= How do I create a survey? =

Go to PollQuest → Surveys → Add New Survey. You can choose from pre-built templates or start completely from scratch with your own questions.

= Can I customize the survey appearance? =

Yes. You can customize the widget color, position (bottom-right, bottom-left, bottom-center), and the confirmation message shown after a respondent submits the survey.

= Does this plugin support file uploads? =

Yes, PollQuest supports file uploads as a question type with configurable file type restrictions and maximum file size limits.

= Can I export survey responses? =

Yes. You can export all responses as a CSV file directly from the Results page inside the PollQuest dashboard.

= Does this work with page builders? =

Yes, PollQuest works with all page builders including Elementor, Divi, and Gutenberg using the built-in shortcode.

= Is this plugin GDPR compliant? =

PollQuest is designed with privacy in mind. All survey and response data is stored locally in your WordPress database. No data is sent to external services by default. Optionally, if the site owner enables the Gravatar avatar setting, a hash of respondent email addresses is sent to Gravatar.com to display profile photos — this feature is off by default and must be explicitly enabled. GDPR compliance also depends on your own site's data retention and consent practices.

== Installation ==

1. Install the PollQuest plugin for WordPress via the WordPress.org plugin repository or by uploading the files to your server.
2. Activate the PollQuest plugin.
3. Navigate to the PollQuest tab in your WordPress admin menu.
4. Create your first survey and start collecting feedback!

== Privacy Policy ==

This plugin stores all survey and response data in your WordPress database. No data is sent to external services by default. If the site owner enables the optional Gravatar avatar setting, a hash of respondent email addresses is sent to gravatar.com to load profile photos — this is off by default and opt-in only.
